# Láminas de Instagram — Dr. Waldo Ortega

Carpeta de trabajo de los carruseles de Instagram de @dr_waldo_ortega.

- `carruseles/`: una carpeta por carrusel (`AAAA-MM-DD-tematica-tema`), con las láminas numeradas en el orden de publicación.
- `plantilla/`: plantilla, fuentes y programa que convierte las láminas en imágenes.

Regla fija: aquí solo van láminas listas para Instagram. Nunca fotos de pacientes ni información privada.
